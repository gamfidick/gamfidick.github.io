📊 Immich-Insights - See Your Photo Library Stats

Immich Insights is a self-hostable Docker container that displays statistics for assets of an Immich account using the Immich API. It gives you a simple, clear view of your photo and video library without spreadsheets or manual counting.

Download Immich-Insights

Visit this link to download the application: Immich-Insights on GitHub.

✨ What It Does

Immich-Insights connects to your Immich account through the Immich API and turns your asset information into easy-to-read statistics. Instead of opening folders one by one, you can see the bigger picture of your library. It is built for people who want useful numbers without needing to write code or use complicated database tools.

The app is self-hostable, which means it runs on your own computer or server. Your Immich account details and library statistics stay under your control. It is packaged as a Docker container, so the project is delivered as a ready-made application package rather than a set of loose script files.

Getting started with Immich-Insights does not require programming knowledge. You will visit the download page, get the application files, and then run the container on your Windows computer. 🔧 How to Use

Immich-Insights is designed to be straightforward. After the container starts, open the web address shown in the setup instructions. You will see a page with statistics for your Immich account. The exact layout may include totals for photos, videos, and storage, along with other useful numbers about your library. Use these figures to understand your collection, plan backups, or decide when it is time to tidy up.

If the page asks for connection details, enter the information for your Immich account as described on the download page. This may include the address of your Immich server and an API key or account credentials. Treat this information like a password. You can keep Immich-Insights running in the background and check it whenever you want an updated view. ❓ Troubleshooting

If the download page does not open, check your internet connection and try again. If you are on a work or school network, some sites may be blocked. Try a different network or ask your network administrator for help. The official link is the safest place to get Immich-Insights, so avoid downloading the application from other websites.

If Docker is not installed or not running, Immich-Insights cannot start. Open Docker Desktop on Windows and make sure it is running before you try again. If you see an error about Docker not being found, install Docker for Windows from the official Docker website, then restart your computer and repeat the setup steps from the download page.

If the statistics page does not load, confirm that you used the correct web address and that the container is still running. Check the download page for any recent notes or updates. If you changed your Immich password or API key, update the connection details in Immich-Insights as described by the project. When in doubt, return to the download page and follow the instructions from the beginning.
